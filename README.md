# Hospital-Operations-Dashboard---PowerBI
Objective
To analyze hospital performance metrics including patient admissions, treatment costs, department efficiency, doctor performance, and gender distribution.
<img width="1396" height="810" alt="image" src="https://github.com/user-attachments/assets/a14bd179-c348-47e7-9595-d1757e2568f2" />

### 📊 Key KPIs
- Maximum Treatment Cost
- Minimum Treatment Cost
- Average Length of Stay
- Total Treatment Cost
- Total Patient Count

### 📈 Insights Delivered
- Department-wise patient distribution
- Monthly admission trends
- Doctor-wise performance analysis
- Gender distribution of patients
- Treatment cost comparison across departments

### 🛠 Tools Used
- Power BI
- DAX (Calculated Measures & KPIs)
- Data Modeling
- Interactive Slicers
